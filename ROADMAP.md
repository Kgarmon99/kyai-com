# KYAI Roadmap

## Phase 1: Contributor Operating System

- Public Build with KYAI section
- Contributor roles, missions, badges, and review pipeline
- GitHub issue forms for signals, events, profiles, missions, toolkits, and bugs
- Contribution docs, editorial policy, and data contracts

## Phase 2: Source Desk

- GitHub issues created from public site forms
- Editor queue by region, category, and status
- Source reviewer checklist
- Correction workflow
- Source trust desk on the public site with review status, confidence, source coverage, and correction links
- Intelligence automation rejects non-Kentucky region labels for OpenAlex research matches

## Phase 3: Regional Pages

- Shareable pages for Louisville, Bluegrass, Western Kentucky, Appalachia, Northern Kentucky, and South Central Kentucky
- Open maintainer cards for each region
- Local events, people, toolkits, and missions
- Generated `/regions/<region>/` pages with signals, events, profiles, recommended toolkits, open questions, and partner asks

## Phase 4: Public Distribution

- Contributor credits
- Badges and share cards
- Weekly mission board
- Embeddable region widgets for partners
- Public JSON/API feeds for signals, events, and profiles
- Standalone signal pages with review metadata and share actions
- Standalone toolkit pages with OpenGraph metadata and improvement links
- Weekly post/share-card kit powered by current feed data

## Phase 5: Community Programs

- Workshop host network
- School, library, small business, and civic toolkit library
- Regular signal review calls
- Founding contributor spotlight
- Kentucky AI calendar for conferences, workshops, public meeting watches, open host slots, and contributor calls
- Role-aware newsletter preferences for business owners, teachers, students, founders, civic leaders, journalists, and researchers
